# WedTech Solutions

WedTech Solutions is a full-stack wedding technology platform built for professional wedding planners. It consists of two tightly integrated products:

<CardGroup cols={2}>
  <Card title="Wedding CRM" icon="briefcase" href="/crm/overview">
    A complete CRM for managing leads, weddings, vendors, checklists, client portals, and RSVP integration — all in one place.
  </Card>
  <Card title="RSVP Platform" icon="envelope" href="/rsvp/overview">
    A guest-facing RSVP management system with digital invites, QR check-in, seating charts, photo walls, and multi-channel reminders.
  </Card>
</CardGroup>

## How the two products work together

The CRM and RSVP Platform communicate bidirectionally: the CRM pushes guest lists to the RSVP Platform and pulls live headcounts and RSVP status back. Whenever a guest submits an RSVP, the RSVP Platform fires a real-time webhook to the CRM so the planner always has up-to-date data — even across disconnected systems.

```
CRM (Port 3001) ◄──────── Webhooks ────────► RSVP Platform (Port 3000)
     │                                               │
     └──── REST API proxy ───────────────────────────┘
```
