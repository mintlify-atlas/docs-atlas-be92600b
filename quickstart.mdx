## Prerequisites

Before you begin, make sure you have:

- **Node.js** 18+ (20+ recommended)
- **PostgreSQL** 14+ (for the RSVP Platform)
- **Homebrew** (macOS) — for installing PostgreSQL
- **Git** — to clone the repository

<Steps>
  <Step title="Install PostgreSQL">
    If you don't have PostgreSQL installed, use Homebrew:

    ```bash
    brew install postgresql@17
    brew services start postgresql@17

    # Create the postgres role and database
    psql -h localhost -U $(whoami) -d postgres -c "CREATE ROLE postgres WITH LOGIN SUPERUSER PASSWORD 'postgres';"
    createdb -U postgres wedding_rsvp
    ```

    <Note>
      The `wedding_rsvp` database name must match your `DATABASE_URL` in `RSVP/.env`.
    </Note>
  </Step>

  <Step title="Start the Wedding CRM (Terminal 1)">
    The CRM uses SQLite — no external database setup is required.

    ```bash
    cd SaaS/wedding-crm

    # Install dependencies
    npm install

    # Apply database migrations (creates SQLite dev.db)
    npx prisma migrate deploy

    # Seed with demo data (creates demo users, leads, weddings, vendors)
    npm run seed

    # Start the development server
    npm run dev
    ```

    The CRM is now running at **http://localhost:3001**

    <Tip>
      The seed script creates 4 demo accounts. Use `admin@wedcrm.com` / `admin123` to log in.
    </Tip>
  </Step>

  <Step title="Start the RSVP Platform (Terminal 2)">
    The RSVP Platform uses PostgreSQL.

    ```bash
    cd RSVP

    # Install dependencies
    npm install

    # Push schema to PostgreSQL and create all tables
    npx prisma db push

    # Generate the Prisma client
    npx prisma generate

    # Start the development server
    npm run dev
    ```

    The RSVP Platform is now running at **http://localhost:3000**
  </Step>

  <Step title="Create a planner account">
    1. Open **http://localhost:3000/register**
    2. Enter your name, email, and a password
    3. Click **Register** — an API key is automatically generated for your account

    <Note>
      To find your API key, run `npx prisma studio` inside the `RSVP/` directory and inspect the `planners` table.
    </Note>
  </Step>

  <Step title="Configure environment variables">
    Copy and configure the environment files:

    **RSVP Platform** (`RSVP/.env`):
    ```bash
    DATABASE_URL="postgresql://postgres:postgres@localhost:5432/wedding_rsvp"
    NEXTAUTH_URL="http://localhost:3000"
    NEXTAUTH_SECRET="your-random-secret-here"
    HMAC_SECRET="your-hmac-secret-here"
    ```

    **Wedding CRM** (`SaaS/wedding-crm/.env`):
    ```bash
    DATABASE_URL="file:./dev.db"
    NEXTAUTH_SECRET="your-random-secret-here"
    NEXTAUTH_URL="http://localhost:3001"
    CRM_BASE_URL="http://localhost:3001"
    ```

    <Warning>
      Generate strong random values for `NEXTAUTH_SECRET` and `HMAC_SECRET` in production: `openssl rand -base64 32`
    </Warning>
  </Step>

  <Step title="Connect the CRM to the RSVP Platform">
    Link the two products together so they can exchange guest data in real time:

    1. Open **http://localhost:3001** and log in with `admin@wedcrm.com` / `admin123`
    2. Open any wedding from the **Weddings** page
    3. Click the **RSVP & Guests** tab
    4. Click **Connect RSVP Platform**
    5. Enter:
       - **RSVP Platform URL**: `http://localhost:3000`
       - **Wedding ID**: the ID from the RSVP Platform's `weddings` table
       - **API Key**: your planner's API key from Step 4
    6. Click **Test Connection** — you should see a green success indicator
    7. Click **Save & Connect**
    8. Click **Sync from RSVP** to pull all existing guest data

    <Info>
      When you save the connection, the CRM automatically registers its webhook URL (`http://localhost:3001/api/webhooks/rsvp`) with the RSVP Platform, enabling real-time RSVP updates.
    </Info>
  </Step>
</Steps>
