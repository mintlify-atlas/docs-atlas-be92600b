---
title: "Seating"
description: "Manage seating tables and guest assignments for events. Supports visual X/Y positioning for drag-and-drop chart editors."
---

<Note>
  All endpoints require a valid **NextAuth session cookie**. Table numbers must be unique per `(weddingId, eventId, tableNumber)` combination.
</Note>

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/weddings/:weddingId/seating` | List tables with assigned guests |
| `POST` | `/api/weddings/:weddingId/seating` | Create a new table |
| `PATCH` | `/api/weddings/:weddingId/seating/:tableId` | Update a table |
| `DELETE` | `/api/weddings/:weddingId/seating/:tableId` | Delete a table |

---

## GET /api/weddings/:weddingId/seating

Returns a paginated list of seating tables. Each table includes its event details and assigned guests.

### Query parameters

<ParamField query="page" type="number">Page number. Default `1`.</ParamField>
<ParamField query="pageSize" type="number">Results per page. Default `50`.</ParamField>
<ParamField query="eventId" type="string">Filter tables by event ID.</ParamField>

```bash
curl "http://localhost:3000/api/weddings/clx1abc123/seating?eventId=evt_2" \
  -H "Cookie: next-auth.session-token=<token>"
```

**200 OK**

## POST /api/weddings/:weddingId/seating

Creates a new seating table for a specific event.

### Request body

<ParamField body="eventId" type="string" required>
  ID of the event this table belongs to.
</ParamField>

<ParamField body="tableNumber" type="number" required>
  Numeric table identifier (must be ≥ 1 and unique per event).
</ParamField>

<ParamField body="capacity" type="number" required>
  Maximum number of guests at the table. Must be ≥ 1.
</ParamField>

<ParamField body="label" type="string">
  Human-readable label (e.g. `"Rose Table"`, `"Table 5"`).
</ParamField>

<ParamField body="zone" type="string">
  Seating zone (e.g. `"Stage Side"`, `"Entrance"`, `"Garden"`).
</ParamField>

<ParamField body="positionX" type="number">
  X coordinate for visual seating chart canvas.
</ParamField>

<ParamField body="positionY" type="number">
  Y coordinate for visual seating chart canvas.
</ParamField>

```bash
curl -X POST http://localhost:3000/api/weddings/clx1abc123/seating \
  -H "Content-Type: application/json" \
  -H "Cookie: next-auth.session-token=<token>" \
  -d '{
    "eventId": "evt_2",
    "tableNumber": 1,
    "capacity": 10,
    "label": "Rose Table",
    "zone": "Garden",
    "positionX": 120.5,
    "positionY": 300.0
  }'
```

**201 Created** — returns full table record with `event` and `assignedGuests`.

### Error responses

| Status | Error |
|--------|-------|
| 400 | `"eventId, tableNumber, and capacity are required"` |
| 400 | `"tableNumber must be at least 1"` |
| 400 | `"capacity must be at least 1"` |
| 404 | `"Event not found in this wedding"` |
| 409 | `"Table number 1 already exists for this event"` |

## PATCH /api/weddings/:weddingId/seating/:tableId

Partially updates a seating table. All create-time fields except `eventId` and `weddingId` are updatable.

```bash
curl -X PATCH http://localhost:3000/api/weddings/clx1abc123/seating/tbl_1 \
  -H "Content-Type: application/json" \
  -H "Cookie: next-auth.session-token=<token>" \
  -d '{"label": "Gold Table", "positionX": 150.0, "positionY": 280.0}'
```

---

## DELETE /api/weddings/:weddingId/seating/:tableId

Deletes the seating table. Guest invite records that referenced this table will have `seatingTableId` set to `null`.

```bash
curl -X DELETE http://localhost:3000/api/weddings/clx1abc123/seating/tbl_1 \
  -H "Cookie: next-auth.session-token=<token>"
```

**200 OK**
```json
{ "success": true, "data": { "deleted": true }, "error": null, "meta": null }
```
