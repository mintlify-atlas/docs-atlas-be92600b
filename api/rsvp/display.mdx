---
title: "Live Display"
description: "Generate time-limited display tokens and serve live RSVP count data for large-screen display boards."
---

<Note>
  Token generation requires a **NextAuth session cookie**. The display data endpoint is **public** but gated by a time-limited token passed as a query parameter.
</Note>

## Endpoints

| Method | Endpoint | Auth | Description |
|--------|----------|------|-------------|
| `POST` | `/api/weddings/:weddingId/display-tokens` | Planner | Generate a display token |
| `GET` | `/api/display/:weddingCode?token=xxx` | Token in query | Live display data |

---

## POST /api/weddings/:weddingId/display-tokens

Generates a time-limited display token for a wedding. The token is used to access the live display endpoint without a session.

### Request body

<ParamField body="hoursValid" type="number">
  Number of hours the token remains valid. Defaults to `24`.
</ParamField>

```bash
curl -X POST http://localhost:3000/api/weddings/clx1abc123/display-tokens \
  -H "Content-Type: application/json" \
  -H "Cookie: next-auth.session-token=<token>" \
  -d '{"hoursValid": 8}'
```

**201 Created**
```json
{
  "success": true,
  "data": {
    "token": "clx_display_token_xyz",
    "expiresAt": "2026-05-15T26:00:00.000Z",
    "url": "http://localhost:3000/display/ananya-rohan-2026?token=clx_display_token_xyz"
  },
  "error": null,
  "meta": null
}
```

### Response fields

<ResponseField name="data.token" type="string">
  The display token value.
</ResponseField>

<ResponseField name="data.expiresAt" type="string">
  ISO 8601 expiry time.
</ResponseField>

<ResponseField name="data.url" type="string">
  Full shareable URL for the display screen.
</ResponseField>

### Error responses

| Status | Error |
|--------|-------|
| 401 | `"Unauthorized"` |
| 404 | `"Wedding not found"` |

## GET /api/display/:weddingCode

Returns live RSVP counts for all active events in a wedding. Intended for large-screen display boards.

### Query parameters

<ParamField query="token" type="string" required>
  Display token generated by `POST /api/weddings/:weddingId/display-tokens`.
</ParamField>

```bash
curl "http://localhost:3000/api/display/ananya-rohan-2026?token=clx_display_token_xyz"
```

**200 OK**
```json
{
  "success": true,
  "data": {
    "brideName": "Ananya",
    "groomName": "Rohan",
    "primaryColorHex": "#B8860B",
    "secondaryColorHex": "#800020",
    "events": [
      {
        "name": "Sangeet Night",
        "date": "2026-05-13T19:00:00.000Z",
        "attending": 72,
        "declined": 10,
        "pending": 18,
        "totalInvited": 100
      },
      {
        "name": "Reception",
        "date": "2026-05-15T18:00:00.000Z",
        "attending": 126,
        "declined": 32,
        "pending": 62,
        "totalInvited": 220
      }
    ],
    "lastUpdated": "2026-05-15T18:45:00.000Z"
  },
  "error": null,
  "meta": null
}
```

### Response fields

<ResponseField name="data.brideName" type="string">Bride's name for display.</ResponseField>
<ResponseField name="data.groomName" type="string">Groom's name for display.</ResponseField>
<ResponseField name="data.primaryColorHex" type="string">Brand colour for theming the display.</ResponseField>
<ResponseField name="data.secondaryColorHex" type="string">Secondary brand colour.</ResponseField>
<ResponseField name="data.events" type="array">
  Array of active events with live counts: `name`, `date`, `attending`, `declined`, `pending`, `totalInvited`.
</ResponseField>
<ResponseField name="data.lastUpdated" type="string">ISO 8601 timestamp of the response.</ResponseField>

### Error responses

| Status | Error |
|--------|-------|
| 401 | `"Display token is required"` |
| 403 | `"Invalid display token"` |
| 403 | `"Token does not match this wedding"` |
| 403 | `"Display token has expired"` |
| 404 | `"Wedding not found"` |
