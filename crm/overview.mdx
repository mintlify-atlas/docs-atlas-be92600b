The Wedding CRM (Product 1) is a full-featured Customer Relationship Management system built for wedding planners. It runs at **http://localhost:3001** on a SQLite database via LibSQL and Prisma, and integrates bidirectionally with the RSVP Platform (Product 2) on port 3000.

## Modules

  <Card title="Lead pipeline" icon="filter" href="/crm/modules/lead-pipeline">

  <Card title="Wedding dashboard" icon="house" href="/crm/modules/wedding-dashboard">
    Central command center for each wedding with 6 tabs: Functions, Vendors, Checklists, Payments, Timeline, and RSVP & Guests.
  </Card>
  <Card title="Checklists & SOPs" icon="list-check" href="/crm/modules/checklist-sop">

  <Card title="Vendor management" icon="store" href="/crm/modules/vendor-management">
    Vendor database with 16 categories, assignment to weddings and functions, follow-up tracking, and price range classification.

  <Card title="Data library" icon="book-open" href="/crm/modules/data-library">

## CRM pages

| Route | Description |
| --- | --- |
| `/login` | Authentication page with demo credential hints |
| `/dashboard` | Overview with lead stats, revenue, and upcoming tasks |
| `/leads` | Lead pipeline with filters, search, and CSV import |
| `/leads/import` | Bulk data import for leads, vendors, and weddings |
| `/weddings` | Wedding project list with status filters |
| `/weddings/:id` | Wedding detail with 6 tabbed modules |
| `/vendors` | Vendor directory with category and city filters |
| `/checklists` | SOP template library and applied checklists |
| `/library` | Knowledge base and document library |
| `/portal` | Client portal access management |
