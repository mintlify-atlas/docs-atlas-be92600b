title: "Wedding dashboard"
description: "Central command center for managing every aspect of a wedding project at /weddings/:id."
---

Each wedding has a dedicated detail page at `/weddings/:id` that acts as the command center for the entire project. The page opens with a header card showing client names, venue, guest count, budget, and a live **countdown timer** (days until the wedding).

## Stats overview

Four summary tiles beneath the header show at a glance:

| Tile | Source |
| --- | --- |
| Functions count | `wedding.functions.length` |
| Vendors count | `wedding.vendorAssignments.length` |
| Tasks count | Sum of checklist items across all checklists |
| Payments count | `wedding.payments.length` |

## Wedding function management

The **Functions** tab lets you add ceremony segments to a wedding. The available function names are:

`Mehendi`, `Sangeet`, `Haldi`, `Wedding Ceremony`, `Reception`, `Cocktail Party`, `Engagement`, `Ring Ceremony`, `Welcome Dinner`, `Phera`, `Vidaai`, `After Party`

Each function record stores:

| Field | Type | Description |
| --- | --- | --- |
| `name` | String | Function name |
| `date` | DateTime? | Date of the function |
| `venue` | String? | Venue for this function |
| `budget` | Float? | Budget allocated |
| `guestCount` | Int? | Expected guests |
| `status` | String | `PLANNING`, `CONFIRMED`, `IN_PROGRESS`, `COMPLETED` |
| `notes` | String? | Free-text notes |

Click **Add Function** to open the modal and select a function name, date, and venue.

### Task tracking per function

Each `WeddingFunction` has a set of `FunctionTask` records. Tasks carry a `title`, `status` (`PENDING` / `IN_PROGRESS` / `COMPLETED`), `priority`, optional `dueDate`, and `description`.

## Budget tracking

Budgets are tracked at two levels:

- **Wedding level** — the overall budget stored on the `Wedding` record, displayed in the header card as `₹X.XL`.
- **Function level** — each `WeddingFunction` has its own `budget` field visible on the function card.

Payments are recorded separately in the **Payments** tab with statuses `PENDING`, `RECEIVED`, and `OVERDUE`.

## API reference

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/api/weddings` | List all weddings with optional `status` and `search` filters |
| `POST` | `/api/weddings` | Create a wedding |
| `GET` | `/api/weddings/:id` | Fetch a single wedding with all relations |
| `PUT` | `/api/weddings/:id` | Update wedding fields |
| `DELETE` | `/api/weddings/:id` | Delete wedding (cascades to all children) |
| `POST` | `/api/weddings/:id/functions` | Add a new function to a wedding |
